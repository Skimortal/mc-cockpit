# Datenschutzerklärung – MOST Connect LPN-Helfer

Stand: 2026-06. Verantwortlich: MOST Connect KG.

Diese Browser-Erweiterung unterstützt das interne Anlegen von LPNs im Manhattan-
Lagerportal (ALDI/Hofer).

## Welche Daten werden verarbeitet?
- **Portal-Zugangsdaten** (Benutzername/Passwort), die der Nutzer **selbst** im Panel
  eingibt, um den Login zu automatisieren.
- **Arbeitsdaten** des aktuellen Vorgangs (PO-Nummer, MHD, Palettenzahl aus dem
  „Manhattan-Code").

## Wie werden die Daten gespeichert/genutzt?
- Ausschließlich **lokal im Browser des Nutzers** (`chrome.storage.local`).
- Die Daten werden **nicht an Server übertragen**, **nicht verkauft** und **nicht an
  Dritte weitergegeben**. Die Erweiterung lädt keinen externen Code nach.
- Die Zugangsdaten werden nur verwendet, um die Login-Felder des Manhattan-Portals
  auszufüllen.

## Wo läuft die Erweiterung?
- Nur auf Seiten von `*.aldi-sued.com` (dem Manhattan-Portal).

## Löschen
- Über „Login löschen" im Panel oder durch Entfernen der Erweiterung werden die lokal
  gespeicherten Daten gelöscht.
